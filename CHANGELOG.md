# Changelog

All notable changes to this project are documented here.

## v1.2 - 2026-09-19

- Fixed the filename label overlapping the naming dropdown.
- Added persistent settings for the download folder, naming mode, and retry count.
- Set a safer minimum window width to preserve the control layout.

## v1.1 - 2026-09-19

- Fixed multiple pasted URLs being incorrectly treated as a single download task.

## v1.0 - 2026-09-19

- Initial Windows GUI release.
- Added URL extraction, duplicate removal, automatic retries, two naming modes, progress reporting, cancellation, and failed-link reports.
